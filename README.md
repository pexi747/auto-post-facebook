# 📢 FixPack Multi-Page Facebook Auto-Pilot & Content System

ระบบบริหารจัดการเพจ Facebook อัตโนมัติ รองรับ **หลายเพจ (Multi-Page Management)**, **กำหนดสิทธิ์ผู้ใช้หลายระดับ (RBAC)**, **ปฏิทินโพสต์ล่วงหน้า (Content Calendar)** และ **ระบบคิดคอนเทนต์ด้วย AI + Auto-Pilot 24 ชม.**

---

## 🌍 วิธีการเข้าใช้งาน (ทั้งภายในและภายนอกบ้าน)

### 1. เข้าจากคอมพิวเตอร์เครื่องนี้ (Localhost)
เปิดเบราว์เซอร์ไปที่:
👉 **`http://localhost:5050`**

### 2. เข้าจากมือถือในวง Wi-Fi เดียวกัน (Local Wi-Fi)
นำมือถือหรือแท็บเล็ตที่ต่อ Wi-Fi เดียวกัน เปิดเบราว์เซอร์แล้วพิมพ์:
👉 **`http://192.168.1.163:5050`**

### 3. เข้าจากอินเตอร์เน็ตภายนอก (4G / 5G / นอกบ้าน) 🌐
ผมได้เตรียมไฟล์สำหรับเปิดอุโมงค์ออนไลน์ไว้ให้แล้ว:
1. เปิดโปรแกรมเว็บด้วย **`start_web.bat`** ตามปกติ
2. ดับเบิ้ลคลิกเปิดไฟล์ **`start_internet_tunnel.bat`**
3. ระบบจะสร้างลิงก์อินเตอร์เน็ตความปลอดภัยสูงแบบ **HTTPS** ให้ทันที (เช่น `https://xxxx.loca.lt`)
4. คุณสามารถคัดลอกลิงก์นั้นไปเปิดในมือถือผ่าน 4G/5G หรือส่งให้ทีมงานเข้าใช้งานจากที่ไหนในโลกก็ได้!

### 4. รันบนคลาวด์ตลอด 24 ชั่วโมง (Cloud Hosting - ไม่ต้องเปิดคอมทิ้งไว้)
หากต้องการให้ระบบทำงานตลอด 24 ชม. โดยไม่ต้องเปิดคอมพิวเตอร์ที่บ้านทิ้งไว้:
- โปรเจกต์นี้มีไฟล์ `Dockerfile` และ `Procfile` รองรับการนำขึ้นโฮสติ้งฟรี/ราคาประหยัด เช่น **Render.com**, **Railway.app** หรือ **VPS** ได้ทันที
